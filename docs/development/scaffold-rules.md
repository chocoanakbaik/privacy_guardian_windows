# Scaffold Rules

This repository scaffold separates implementation concerns before feature logic is written.

- C# files define executable behavior and contracts.
- JSON files define data-driven rules, configuration, schemas, lexicons, profiles, and templates.
- PowerShell scripts define repeatable local build/test/verification tasks.
- YAML defines CI automation.
- Markdown defines architecture, security, development, and ownership decisions.
- Test fixtures and expected JSON provide deterministic analysis inputs/outputs.

Empty or scaffold-only files must not be treated as completed features.
